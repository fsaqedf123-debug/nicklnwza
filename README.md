# ระบบประเมินผลรายวิชา 640-394 ปฏิบัติการพยาบาลเด็ก
### คณะพยาบาลศาสตร์ มหาวิทยาลัยสงขลานครินทร์ (PSU Faculty of Nursing)

เว็บแอปพลิเคชันภาษาไทยสำหรับการประเมินผลการจัดการเรียนการสอน รายวิชา 640-394 ปฏิบัติการพยาบาลเด็ก รองรับการใช้งานจริงบนมือถือ (Mobile), แท็บเล็ต (Tablet) และคอมพิวเตอร์ (Desktop) ออกแบบด้วยสีกรมท่า ฟ้าอ่อน และขาว พร้อมหน้าประเมินสำหรับนักศึกษา และแผงควบคุมสรุปผลทางสถิติสำหรับอาจารย์ผู้ประสานงานรายวิชา

## 🌟 คุณสมบัติเด่นของระบบ

### 1. ฝั่งนักศึกษา (Student Evaluation Wizard)
- **การออกแบบ Mobile Card View**: บนสมาร์ตโฟนแสดงข้อประเมินเป็นการ์ดพร้อมปุ่มเลือกระดับคะแนนขนาดใหญ่ หลีกเลี่ยงตารางแนวนอนที่ต้องเลื่อนซ้ายขวา
- **ระบบ Stepper 8 ขั้นตอน พร้อม Progress Bar**: ข้อมูลที่ตอบแล้วไม่สูญหายเมื่อย้อนกลับไปแก้ไข
- **ไม่เลือกคะแนนเริ่มต้น**: ป้องกันการตอบโดยไม่ได้ตั้งใจ (No pre-selected rating)
- **เงื่อนไขบังคับข้อคิดเห็นอัตโนมัติ**: เมื่อให้คะแนน 1, 2 หรือ 3 ระบบจะแสดงกล่องข้อคิดเห็นทันทีและบังคับกรอกข้อความจริง (ตรวจจับข้อความว่างและช่องว่างล้วน ทั้งฝั่งหน้าเว็บและเซิร์ฟเวอร์)
- **คัดกรองแหล่งฝึกอย่างแม่นยำ**:
  - หมวด 4.2: ถามก่อนว่าได้ขึ้นฝึก ณ ฝ่ายพัฒนาเด็กปฐมวัยหรือไม่ หากไม่ได้ขึ้นฝึกจะข้ามและบันทึกสถานะ `not_trained`
  - หมวด 4.3: เลือกหอผู้ป่วยจริงแยกตาม 3 โรงพยาบาล (รพ.มอ., รพ.หาดใหญ่, รพ.สงขลา) หรือเลือก "ไม่ได้ขึ้นฝึกบนหอผู้ป่วย" โดยแยก NICU และ PICU ของแต่ละโรงพยาบาลออกจากกันอย่างชัดเจนด้วยรหัสถาวร
  - หากย้อนกลับไปยกเลิกหอผู้ป่วย ระบบจะตัดคำตอบเดิมของหอนั้นทิ้งทันที
- **รองรับข้อประเมินใหม่ครบถ้วน**:
  - 4.4 การจัดกิจกรรมการเล่นบนหอผู้ป่วย
  - 4.5 การอภิปรายกรณีเลือกสรรในวันแรกของสัปดาห์ที่ 8
  - 4.6 การสอบลงกอง (OSPE 7 ข้อ) รักษารหัสถาวรเดิม
  - 4.7 ความพึงพอใจภาพรวม และคำถามปลายเปิด
- **ระบบป้องกันการส่งซ้ำ**: ใช้ `submission_token` (Idempotency Key) และปิดการกดปุ่มส่งซ้ำระหว่างบันทึก
- **ความเป็นส่วนตัว 100%**: ไม่เก็บชื่อ รหัสนักศึกษา อีเมล หรือเบอร์โทรศัพท์

### 2. ฝั่งผู้ประสานงานรายวิชา (Admin & Coordinator Dashboard)
- **ระบบตรวจสอบสิทธิ์ฝั่งเซิร์ฟเวอร์**: ป้องกันไม่ให้นักศึกษาเข้าถึงผลประเมินหรือข้อคิดเห็นของผู้อื่น
- **จัดการรอบประเมิน**: กำหนดภาคการศึกษา ปีการศึกษา (ไม่ hardcode ค่าปี) และเปิด-ปิดรับแบบประเมินได้ตลอดเวลา
- **สถิติถูกต้องตามหลักการวัดผล**:
  - คำนวณค่าเฉลี่ย (Mean) จากคะแนน 1–5 เท่านั้น (ไม่รวม N/A)
  - หากไม่มีคะแนน แสดง "ไม่มีข้อมูลคะแนน" แทนเลข 0
  - ร้อยละของคะแนนแต่ละระดับ (1–5) และร้อยละคะแนนไม่พึงพอใจ (1–3) คำนวณโดยใช้จำนวนผู้ตอบ 1–5 ในข้อนั้นเป็นตัวหาร
  - แสดง N/A, สถานะไม่ได้ขึ้นฝึก และสถานะไม่มีในฉบับที่ตอบ (สำหรับรอบที่เป็นเวอร์ชันเก่า) แยกต่างหาก
  - ไม่รวมคะแนนเฉลี่ยข้ามหอผู้ป่วยหรือข้ามหมวดโดยอัตโนมัติ
- **กราฟและการเปรียบเทียบ**: กราฟการกระจายคะแนน และกราฟเปรียบเทียบค่าเฉลี่ยรายข้อระหว่าง Sec 01–04 ด้วย Chart.js
- **ศูนย์รวมข้อคิดเห็น**: กรองตาม Section, หมวด 4.1–4.7 พร้อมบริบทหอผู้ป่วย/ฐานกิจกรรม
- **ส่งออกข้อมูลภาษาไทย 100%**:
  - Excel (.xlsx) แยก 3 แผ่นงาน: สรุปผลรายข้อ, ข้อมูลคำตอบดิบ, และรายการข้อคิดเห็น
  - CSV รองรับ UTF-8 BOM เปิดใน Microsoft Excel ภาษาไทยได้ทันทีโดยสระไม่เพี้ยน
  - ป้องกัน Formula Injection (CWE-1236) โดย sanitize อักขระ `=`, `+`, `-`, `@` นำหน้าข้อความอย่างปลอดภัย
- **Sandbox ข้อมูลทดสอบ**: มีระบบสร้างข้อมูลทดสอบจำลอง (36 รายการ) และลบทิ้งได้ทุกเมื่อ โดยแยกขาดจากข้อมูลจริงด้วยธง `is_test_data`

## 📋 รายการรหัสถาวรของข้อประเมิน (Permanent Codes)

- **4.1.1**: `SEC_4_1_1_SKILLS_W1` (การสอบทักษะทางการพยาบาลเด็กในสัปดาห์ที่ 1)
- **4.1.2 Clinical teaching (9 ข้อ)**:
  - ฐาน ก. CPR ทารกแรกเกิด: `SEC_4_1_2_NEO_BRIEF`, `SEC_4_1_2_NEO_TIME`, `SEC_4_1_2_NEO_EQUIP`
  - ฐาน ข. CPR เด็กเล็ก/เด็กโต: `SEC_4_1_2_CHILD_BRIEF`, `SEC_4_1_2_CHILD_TIME`, `SEC_4_1_2_CHILD_EQUIP`
  - ฐาน ค. Choking: `SEC_4_1_2_CHOKE_BRIEF`, `SEC_4_1_2_CHOKE_TIME`, `SEC_4_1_2_CHOKE_EQUIP`
- **4.2 ฝ่ายพัฒนาเด็กปฐมวัย**: `SEC_4_2_EXP`
- **4.3 ประสบการณ์บนหอผู้ป่วย**: `SEC_4_3_WARD_<ward_code>_EXP` (เช่น `SEC_4_3_WARD_WARD_PSU_NICU_EXP`, `SEC_4_3_WARD_WARD_HY_NICU_EXP`, `SEC_4_3_WARD_WARD_SK_NICU_EXP`)
- **4.4 กิจกรรมการเล่นบนหอผู้ป่วย (ข้อใหม่ v2)**: `SEC_4_4_PLAY_ACTIVITY`
- **4.5 การอภิปรายกรณีเลือกสรร (ข้อใหม่ v2)**: `SEC_4_5_SELECTED_CASE`
- **4.6 การสอบลงกอง OSPE (7 ข้อเดิม)**:
  - `SEC_4_6_OSPE_1_NEB` (พ่นยา)
  - `SEC_4_6_OSPE_2_SUCTION` (Suction)
  - `SEC_4_6_OSPE_3_IV` (IV)
  - `SEC_4_6_OSPE_4_NG` (NG)
  - `SEC_4_6_OSPE_5_WRITTEN` (ข้อเขียน 10 ข้อ)
  - `SEC_4_6_OSPE_6_TIME` (เวลา 7 นาที)
  - `SEC_4_6_OSPE_7_OVERALL` (ภาพรวม OSPE)
- **4.7 ความพึงพอใจภาพรวม**: `SEC_4_7_OVERALL_SATISFACTION`
